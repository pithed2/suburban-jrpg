# Active Runtime Assets

This folder contains the assets currently loaded by the game.

## Characters
- `tilesets/Characters_free/Bob_idle_16x16.png`: Dad player sprite.
- `tilesets/Characters_free/Amelia_idle_16x16.png`: Wife NPC sprite.

## Environment
- `tilesets/Interiors_free/16x16/Interiors_free_16x16.png`: Modern interior tiles and props currently used in the main house and garage clutter.
- `characters/01-generic.png` through `characters/06-conjurer.png`: RPG Maker VX-style character sheets used for placeholder party/NPC sprites.
- `full_set/Characters/Actors_4.png`, `Chests.png`, `!Doors.png`, `!other.png`: RPG Maker-style object and actor sheets currently loaded by BootScene.
- `full_set/Tilesets/Int-A2.png`, `Int-A4.png`, `Int-B.png`, `Int-C.png`: 32x32 interior tiles used by the main house scene.
- `tilesets/kitchen_LRK.png`: Kitchen prop spritesheet used by BootScene.
- `tilesets/0x72_16x16DungeonTileset.v5.png`: Dungeon floor and utility clutter frames currently used in the garage.
- `tilesets/suburban-placeholder.png`: Existing Tiled maps still reference this.
- `tilesets/floor-options.png`: Existing basement map still references this.
